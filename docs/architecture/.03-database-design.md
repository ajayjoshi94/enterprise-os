# EnterpriseOS Database Design

## Identity

### users

Purpose:
Stores login accounts.

Fields:

- id (UUID)
- email
- encrypted_password
- status
- created_at
- updated_at

---

### organizations

Purpose:
Represents a company.

Fields:

- id (UUID)
- name
- slug
- status
- timezone
- locale
- created_at
- updated_at

---

### organization_members

Purpose:
Connects users with organizations.

Fields:

- id (UUID)
- organization_id
- user_id
- role
- created_at
- updated_at
